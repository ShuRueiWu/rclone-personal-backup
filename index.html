rclone Personal Backup

This page describes a personal, single-user setup using rclone, an open-source command-line program, to back up selected files from the user's own computer to the user's own Google Drive account.

How it works

rclone runs locally on the user's computer. It connects to Google Drive after the user grants OAuth access, then transfers or checks files as directed by the user. This website does not run the backup.

Google user data

The rclone setup requests Google Drive access needed for backup and verification. The user controls which rclone commands to run. File contents are transferred between the user's computer and the user's Google Drive. This project does not receive or store Google Drive files, OAuth tokens, client secrets, or backup data.
